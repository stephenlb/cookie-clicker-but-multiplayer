# MCP

**MCP** stands for **Model Cookie Protocol**.

It is the (entirely serious) protocol by which a model of a cookie communicates with other cookies, players, and the occasional golden cookie over the multiplayer network.

## Summary

| Field | Value |
|-------|-------|
| Acronym | MCP |
| Expansion | Model Cookie Protocol |
| Transport | PubNub |
| Status | Cookie-ready |
